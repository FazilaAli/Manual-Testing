# Manual Testing Portfolio

This repository showcases my **manual testing skills** through well-structured QA artifacts for a demo web application.  
It includes both **functional testing** deliverables (test cases, bug reports, test plans) and **non-functional testing** coverage (security and performance checklists).

## Contents
- **Test Cases** → Functional test cases in Excel (login, cart, checkout, regression suite)  
- **Test Plans** → Release-level test plan with scope, strategy, entry/exit criteria  
- **Checklists** →  
  - UI checklist (responsiveness, accessibility, consistency)  
  - API checklist (status codes, schema validation, error handling)  
  - Security checklist (authentication, input validation, session management)  
  - Performance checklist (page load, API response time, scalability)  
- **Bug Reports** → Example issues reported in Jira-style format  
- **Exploratory Notes** → Session-based exploratory testing observations  

## Purpose
This repo highlights my ability to:  
- Design **comprehensive manual test cases**  
- Create **structured test plans and strategies**  
- Identify **UI, API, security, and performance quality risks**  
- Report bugs clearly and professionally  
- Perform **exploratory testing with creative, out-of-the-box thinking**  

## Tools & Formats
- **Excel (XLSX)** → Test cases  
- **Markdown (MD)** → Test plans, checklists, bug reports, exploratory notes  
- **PNG/JPG** → Screenshots for bug reports (if needed)

This repository demonstrates how I approach **end-to-end manual QA**: from planning, test design, and execution to identifying functional and non-functional issues.
