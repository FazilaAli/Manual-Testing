# UI Checklist

This checklist ensures the User Interface (UI) is **consistent, usable, and accessible** across devices and browsers.

## General Layout
- [ ] Page loads within 3 seconds on standard broadband
- [ ] Layout is responsive on desktop, tablet, and mobile
- [ ] No horizontal scrollbars on any viewport
- [ ] All pages maintain consistent header, footer, and navigation styles

## Forms & Inputs
- [ ] Mandatory fields are marked clearly (* or text)
- [ ] Placeholder text disappears once typing begins
- [ ] Input fields validate data (e.g., email format, password length)
- [ ] Tab order is logical and flows left-to-right, top-to-bottom

## Visual Consistency
- [ ] Font family and sizes are consistent across pages
- [ ] Button colors match their purpose (primary, secondary, danger)
- [ ] Error messages are styled distinctively (e.g., red, bold)
- [ ] Icons have tooltips or descriptive text

## Accessibility
- [ ] All images have meaningful alt text
- [ ] Page supports screen readers (ARIA labels present where required)
- [ ] Sufficient color contrast between text and background
- [ ] Keyboard navigation works for all interactive elements

## Innovations & Edge Checks
- [ ] Dark mode (if present) maintains readability and design consistency
- [ ] Language/localization switches correctly update UI
- [ ] Hover, active, and focus states are visually distinct
- [ ] Empty states (e.g., empty cart) have friendly illustrations or messages
